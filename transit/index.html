📡 Phase 2: live tracking

We researched free public APIs for Indian bus/train live tracking (Sept 2026). None is reliably free without an API key. So this build ships timetable tools only and never shows fake positions. When the owner adds a key, live data can be wired as an optional enhancement with graceful fallback to this static data.

  • RailRadar (railradar.in/docs) — free tier 1,000 req/month, requires API key — candidate for train live board.
  • Delhi Open Transit Data (otd.delhi.gov.in) — static GTFS public, realtime needs a registered private key.
  • BMTC GTFS — static via community mirrors; realtime not reliably open.
  • NTES / Indian Railways — authoritative, but no public API (official site only).

Meanwhile, for real live train status use the official NTES site.
